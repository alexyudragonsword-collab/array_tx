# 斜视与 EVM

## 当前真值

- **怎么算**（铁律 4）：远场在频域逐频点乘 exp(j2π(f0+f)τ_k(θ))，相移导向 w_k = exp(−j2πf0τ_k) 与频率无关，真延时在频域乘 exp(−j2π(f0+f)τ_k)。
  带边指向：sinθ' = sinθ0·f0/(f0+Δf)，60° / ±200 MHz 偏 0.70°，CW 阵列因子实测与之误差 0.00 %（ex03）。
- **它在波束方向是一个线性频响**：H(f) = (1/n) Σ_k exp(j2πf τ_k(θ0))（Dirichlet 核，`beam.beam_response`），1 于 f=0、带边下垂，二阶跌落 ∝ n²。
  scalar 均衡下的 EVM 残差闭式 `squint_evm_closed_form_db`：60° 时 n=4 −83.9、16 −59.3、32 −47.3、64 −35.2、128 −23.0、256 −10.5 dB（n 翻倍 +12 dB）；30° 低 11 dB。
- **实测**（ex06，FR2 survey、单元误差开、8 符号）：相移 − 真延时 EVM 代价 60°：n=32 +0.02、64 +0.53、128 +4.89 dB，闭式预测 +0.03 / +0.52 / +4.92；
  30° n=128 +0.91 / +0.90。真延时的底与 n 无关（−26.3 ± 0.1，LO 主导）。
- **per-tone 均衡全部抹平**：128 单元 60° 相移阵 −26.86 vs 真延时 −26.87——斜视是逐子载波的线性响应，接收端均衡能消；
  验收口径 `metrics.evm_equalize: scalar` 下斜视才算代价。per-tone 还多抹掉 0.6 dB（0.59–0.65）（单元误差 + 互耦造成的非平坦线性响应）。
- **面阵**（ex08）：斜视规律只看 sinθ，与切面无关；代价看那个切面的波束宽。8 × 8 与 64 × 1 同单元数，60° 时 64 × 1 +0.53 dB，8 × 8 两主面与对角切面 −0.01…−0.04 dB
  （切面上只有 8 个单元宽，波束 28.8°）。

## 被推翻的判断（追加说明，不覆盖）

- 里程碑 1 写"斜视是指向效应不是 EVM 效应"（4 单元 60° 差 0.0002 dB）。它只对 n=4 成立；ex06 把它改成随 n 与扫描角的陈述。

## 3 dB 波束宽（`beam.beamwidth_3db_deg`）

0.886 λ/(L cosθ0) 的数值版，L = 切面方向孔径 + 一个间距；λ/2 线阵 n=4 / 64 / 128 在 60°：50.3° / 3.17° / 1.58°。

> 复核（2026-11-04，ex03 / ex06 / ex08 全尺寸重跑）：ex06 原写 +0.03 / +0.54 / +4.94（预测 +0.03 / +0.53 / +4.95）、per-tone 0.7–1.0 dB，写于面阵里程碑改远邻相位之前；现值见上。ex08 的 64 × 1 原写 +0.54。斜视 0.70°、误差 0.00 %、波束宽 50.3 / 3.17 / 1.58° 均复现。
