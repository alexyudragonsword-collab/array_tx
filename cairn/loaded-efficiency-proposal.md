# 效率进负载模型

> 状态：用户 2026-11-04 批准"按提案做"，已实现（`loadpull.loaded_power_terms`、`info["efficiency"]` 的 `eta_loaded_*` / `eta_array_*`、页面效率卡、ex10）。检验结果在文末。

## 现在怎么算

`info["efficiency"]` 调 polar_tx 的 `PolarResult.avg_efficiency(dpa)`：码流上逐样本取 SCPA 律
η(x) = η_peak·x² / (x² + γ·x(1−x))（默认 γ = 0.67、η_peak = 0.85），η_avg = Σ P_out / Σ P_dc。
x 是匹配负载幅度表上的输出幅度。负载牵引改了 PA 的压缩，但效率仍按匹配负载读。

## 模型（一阶，和负载调制同一个电压模读法）

- **把 SCPA 律拆成两项**：输出功率 P_out(x) = x²，损耗 P_loss(x) = x²(1/η(x) − 1)。
  SCPA 的损耗是单元电容的充放电 C·V²·f，比例于 x(1−x)，**由码决定，与负载无关**（source: assumed，理由同上；Yoo & Walling JSSC 2011 的推导前提）。
- **端口净功率**：电压源 DPA 的前向波 a_k（`amam_loaded` 已给出），有源反射 b_k = Γ_k·a_k。
  端口电流 ∝ a(1−Γ)，电压 ∝ a(1+Γ)，所以净功率 P_net,k = |a_k|²(1 − |Γ_k|²)。
- **单元效率**：η_k = Σ_t P_net,k / Σ_t (P_net,k + P_loss,k)。**阵列效率**：Σ_k Σ_t P_net / Σ_k Σ_t (P_net + P_loss)。
  无损天线下阵列总辐射功率等于各端口净功率之和（Σ|a|² − Σ|b|²），所以阵列效率就是辐射功率 / 直流功率，不用对方向图积分。
- **护栏**：|Γ_k| > 1 的样本（功率倒灌进 PA）净功率记 0 并计数报告；`gamma_max` 默认 0.5，实际不会触发。
- **不改 vendor**：在 `loadpull.py` 里加一个函数，读码流、前向波和 Γ；`info["efficiency"]` 同时给 `matched` 与 `loaded` 两个数，页面卡片显示 loaded 并注明。
  负载牵引关或 S = 0 时 Γ = 0，两个数逐位相等。

## 一个要说清的不一致

里程碑 1 的辐射波形 r_k = y_k + Σ_j S_kj y_j 把泄漏当作由单元 k **再辐射**（方向图失真模型）。
净功率读法把同一个泄漏当作**进入端口 k**。两者在波形上不能同时成立。
提案只用净功率读法算效率（功率），波形和 OTA 指标照旧（铁律 3 不动）。真要统一得换成完整的 S 参数散射模型，那是另一个里程碑，不在这里做。

## 不做 / 边界

- 不做导通损耗 |i|²R_on（随 |1−Γ|² 变）：SCPA 律里没有这一项，加就得有 R_on 的出处。
- 不改 PA 的压缩模型（`amam_loaded` 不动），也不碰 κ。
- 天线无损、isotropic，与里程碑 1 相同。

## 检验结果（2026-11-04，ex10 全尺寸；8 × 8 为 4 符号）

- 实现与提案的一处差别：前向波幅度取带负载的表（`LoadPulledDPA.forward_amplitude`），提案估算时用的是输出幅度。
  广播向压缩变浅时前向波更大，所以 4 × 1 广播向只掉 0.3 个点（估算 0.8）。
- **预期 1 证实**：8 × 8 无 DPD 阵列效率 48.58 → 44.33 %（0°）、→ 46.76 %（30°）、→ 44.02 %（60°）。广播向 ACLR 变好（−36.85 → −44.44 dBc）确实是拿约 4 个效率点换的。
- **预期 2 证实**：4 × 1、CFR 8.5 dB、60° 回退 2 dB 后 loaded 37.43 %，相对无牵引对照 47.9 % 掉 10.4 个点（matched 读法掉 8.2）。
- **预期 3 证实**：8 × 8 无 DPD，内部 / 边缘单元 loaded 效率 0° 42.47 / 46.47 %，60° 42.80 / 45.34 %；单元最低 39.2 %、最高 48.8 %。
- **改写了 ex10 的一条结论**：CFR 6.5 dB + 回退 2 dB 在 matched 读法下几乎不花效率（47.5 % vs 48.4 %）。含 Γ 后是 43.94 %，比无牵引对照低 3.9 个点。
  CFR 换效率仍成立（同回退下 CFR 8.5 → 6.5 dB 多 6.5 个点），但不再"免费"。
- 全程没有 |Γ| > 1 的倒灌样本（`gamma_max` 0.5 截断在先）。
